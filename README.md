# Job Application Tracker

## About the Project
The Job Application Tracker is a web application that helps users organize and track their job applications in one place.

## Technologies Used
- **Frontend:** React
- **Backend:** Node.js and Express.js
- **Database:** MongoDB

## Project Structure
- `frontend/` – User interface
- `backend/` – Server and API
- `.gitignore` – Excludes files that should not be uploaded

## Features
- Track job applications
- Organize application information
- Manage job application records

## Installation and Setup

### 1. Clone the repository
```bash
git clone https://github.com/Albin31j/job-application-tracker.git
cd job-application-tracker
```

### 2. Start the backend
Open a terminal:
```bash
cd backend
npm install
```
Configure your environment variables in a `.env` file, then run the start script defined in `backend/package.json`.

### 3. Start the frontend
Open another terminal:
```bash
cd frontend
npm install
npm run dev
```
